# 偏好文件

位置：`~/.claude/save-for-claude/preferences.md`。对所有项目生效。用户的 `CLAUDE.md` 或记忆中写明的要求优先于此文件。

## 默认偏好

首次引导时以此为初始值，用户只需确认或改动其中几项。写入文件时保留以下格式：

```markdown
# save-for-claude 偏好

## 派单方式
- 时机：方案与用户确认后，实现部分直接派出，不再逐次询问；需求不清时先和用户讨论。
- 汇报：派出时一句话说明派给谁、做什么；完成后汇报评审结果和验收情况。

## 执行器
- codex：启用。模型 gpt-6-astra；单模块、机械改动用 medium，跨模块、需要追链路用 high。
- grok：启用。模型用 Grok 默认配置；每个任务开新会话，同一会话最多续派两次。

## 分工
- Codex：需求清楚、可用测试验收的编码实现、重构、修复、补测试、跨文件机械改动；只读代码调研。
- Grok：X/推特与网络近期信息调研、短上下文分析、创意发散。
- Claude：需求澄清、深入讨论与方案推敲、界面视觉与交互、面向用户的文案、prompt 与文档写作、小改动、所有评审。

## 评审重点
- Codex：删除多余的校验、兜底和重复判断；界面与文案由 Claude 打磨。
- Grok：抽查来源链接与日期，剔除查无实据的结论。
```

## 读取与更新

- 每个会话首次派单前读取一次。
- 用户在对话中改变偏好时（例如“以后调研都交给 Codex”），更新对应条目，并告诉用户已记下。
- 指定的模型不可用时，改用该 CLI 的默认模型完成本次任务，并请用户确认是否更新偏好。
