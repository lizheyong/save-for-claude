# 接入新的执行器

本机有其他 Agent CLI（例如 Gemini CLI）时，先完成以下验证再派单，并把验证过的调用方式告诉用户，建议补进本 skill 的 references：

1. 无头模式：从 `<cli> --help` 找到单次运行并退出的参数，以及从文件或 stdin 读取 prompt 的方式。
2. 登录检查：找一个不调用模型、或只花极少 token 的命令判断登录状态。调用时用 `< /dev/null` 关闭 stdin；输出要求打开浏览器或等待输入，说明未登录，请用户先登录。
3. 权限：确认只读模式和可写模式各用什么参数。
4. 结果：确认能否把最终回复写入文件或输出 JSON，以及会话 id 在哪里。
5. 续派：确认按会话 id 恢复会话的参数。
6. 用一个极小的只读任务实测，确认以上全部可用。

例如 Gemini CLI：无头参数是 `-p`，只读模式是 `--approval-mode plan`，JSON 输出用 `-o json`；不在受信目录运行时会忽略只读设置，未登录时会等待浏览器授权。
